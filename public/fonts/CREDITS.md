# Parish lettering

`parish-serif.json` is an outline subset of Noto Serif, weight 650 and width 100.
The outlines generate actual Three.js TextGeometry for the stone stele, gate plaque and shrine.

Source: https://github.com/google/fonts/tree/main/ofl/notoserif
Copyright 2022 The Noto Project Authors. SIL Open Font License 1.1; see OFL.txt.
The original variable font is retained as source.ttf. Rebuild with
`python scripts/build-parish-font.py` (requires fonttools).
